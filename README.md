# YASEEN LAW PWA

نسخة PWA من موقع YASEEN LAW، جاهزة للنشر على GitHub Pages.

## الملفات
- `index.html` الموقع
- `manifest.webmanifest` إعدادات PWA
- `service-worker.js` التخزين المؤقت والعمل دون اتصال للملفات المحلية
- `icons/` أيقونات PWA

> ملاحظة: الموقع الأصلي يستخدم Tailwind وAOS وFont Awesome وGoogle Fonts من CDN، لذلك لا يمكن ضمان عمل كل الموارد الخارجية دون اتصال حتى يتم تحويلها إلى ملفات محلية.
